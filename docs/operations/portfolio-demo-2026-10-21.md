# Azure 종료 후 포트폴리오 체험판

## 목적과 경계
종료된 Azure 주소 대신 GitHub Pages의 `/Highpass-Project/demo/`로 안내한다.
운영 서버에 목업 모드를 넣지 않고 독립 정적 파일로 구현했다.
환자·의료진·관리자 전환은 인증이 아닌 시나리오 역할 선택이다.

## 구현
- 기존 모델링 지갑 이미지, Pretendard, 공개 합성 CT 예시 한 장 재사용.
- 검사/병원/1·3·7일/열람 전용 조건을 확인하고 체험용 QR 티켓 생성.
- 동일 탭에서 접수 → 공유 기록 → 단기권한 5분 → 영상 열람 연결.
- 철회·기간 만료·중복 QR·병원 불일치·범위 초과·다운로드 거부 체험.
- 체험 이벤트만 그래프/검색/기간 필터/설명/인쇄용 보고서로 연결.
- 고정 진료 질문 담기/취소. 검색 근거 또는 모델 생성이라고 표시하지 않음.
- 기존 소개·화면 모음·README의 Azure 진입 링크를 체험판으로 전환.

## 보안 및 요구사항
관련 기능군: FR-001~025, FR-032~041의 흐름을 설명한다.
해당 FR의 서버 구현이나 운영 검증을 대체하지 않는다.
connect-src none, 외부 API 없음, 카메라/실계정/실제 QR/토큰/환자정보 입력 없음.
상태는 메모리에만 저장한다. 새로고침/초기화는 체험 상태에만 영향을 준다.
공개 이미지에 대한 브라우저 표시 제어는 보안 경계가 아니며 모든 화면에서 체험판임을 명시한다.
증적 원본, 실제 서버 로그, 인증정보는 배포 파일에 포함하지 않는다.
