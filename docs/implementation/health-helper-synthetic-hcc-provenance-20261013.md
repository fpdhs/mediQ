# 홍길동 56세 합성 HCC 사례의 RAG 출처 응답

2026-10-13 KST. 본 변경은 학교 발표용으로 고정된 합성 사례 질문 한 종류에 대한 출처 설명 경로다. 일반 환자 기록 해석이나 임상 RAG 근거 승인으로 보지 않는다.

## 2026-10-14 메인 질문 보강

메인 질문을 `홍길동 56세 건강검진 결과와 AFP, 간 초음파, 간암 시나리오는 어떤 관계가 있나요?`로 고정해 답변 근거를 보강했다. 답변은 2026-10-08 건강검진 중 간 관련 항목(AST·ALT·γ-GTP·C형간염 항체), AFP 세 시점, 세 초음파 기록의 동일 합성 이미지 재사용, 간암 전원 발표 설정을 각각 출처별로 구분한다. 건강검진 참고범위·판정과 AFP 참고범위는 등록되지 않았으며 초음파 실제 촬영·판독문도 없다. 간암 설정은 검사값이나 이미지에서 도출한 진단이 아니다.

이 경로는 `HealthHelperRag`에서 합성 기록의 고정 템플릿으로 응답한다. 응답에 사용한 합성 기록 ID 7개와 종류·날짜 및 발표 설정 ID `HONG_GILDONG_SYNTHETIC_56`을 `scenarioEvidence`에 남기고, 화면에는 자료 버전, 기록 종류·날짜·ID, 별도 발표 설정 출처를 접을 수 있는 근거 패널로 표시한다. 원 질문·기록값은 언어모델과 감사로그에 보내지 않는다. 따라서 실제 Qwen 생성이 아니라 합성 시나리오 출처 요약이며 `generationUsed=false`, `clinicalUse=false`를 유지한다.

## 동작

인증된 환자가 `AFP`, 간 초음파, 간암 사례의 관계를 함께 묻는 경우, 서버가 아래 조건을 모두 확인하면 합성 자료의 제작 출처를 고정 문장으로 안내한다.

- `HIPASS_CAPSTONE_MAIN_SCENARIO=HCC`
- 요청자가 `isScenarioHealthPatient`를 통과
- HCC 합성 카탈로그가 저장소에 정상 등록됨
- 질문이 AFP·초음파·간암 및 관계/출처 의도를 함께 포함

응답은 합성 AFP 세 값과 참고범위 미등록 상태, 같은 합성 초음파 예시 이미지의 반복 사용, 발표에 별도로 작성된 간암 설정의 출처를 설명한다. 서버 측 템플릿만 사용하며 모델 호출, 원문 질문의 모델 전달, 검색 후보 코퍼스 연결은 하지 않는다. 진단·확진·치료 질문은 이 경로보다 먼저 기존 거부 정책을 적용한다. 다른 환자에게는 이 시나리오 값이나 별칭을 제공하지 않는다.

## 안전 경계

응답 메타데이터는 `SYNTHETIC_SCENARIO`, `SYNTHETIC_SCENARIO_ONLY`, `generationUsed=false`, `clinicalUse=false`로 구분한다. 외부 의학 출처 링크나 근거 승인 표시는 만들지 않는다. 시연 값은 실제 진료 기록이 아니며 임상적 정상/이상 또는 위험도를 해석하지 않는다. 학교 데모의 번역 자료·DRAFT 근거 상태를 이 경로에서 변경하지 않는다.

HiPass 요구사항 정의서의 FR-001~FR-046 의료영상 교류 기능에 직접 대응하는 신규 요구사항은 아니다. 환자 인증, 최소 공개, fail-closed, 감사 가능성에 관한 기존 보안 원칙을 보존한다. 새 감사 reason code는 `HELPER_SYNTHETIC_SCENARIO_PROVENANCE`이며 원문 질문·AFP 수치·이름은 감사 행에 저장하지 않는다.
