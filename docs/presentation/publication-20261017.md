# 공개 포트폴리오 갱신 기준

공개 자료 정리일: 2026-10-17. 사용자 제공 「Medi Q 증적.zip」을 기준으로 README, 소개 페이지와 화면 모음을 정리했다. 원본 ZIP은 변경하지 않았다.

## 화면과 접속 경로

- 공개 화면은 `docs/assets/portfolio-20261017/`의 8개 캡처를 사용한다.
- 홈페이지, README, 화면 갤러리와 시연 안내가 같은 자산을 참조한다.
- 기존 `presentation/gallery.html` 주소는 유지하고 내용은 선별한 8개 화면으로 교체했다.
- 계정 선택·내부 Azure 자원·중복 화면은 새 소개 갤러리에서 제외한다.
- QR 캡처는 2026-10-15 만료 표시를 확인했다. 이미지는 변경하지 않고 휴대폰 틀에서 티켓 영역을 표시하며, ‘모바일 제시 예시’와 만료 안내를 붙인다.
- 이미지 원본 SHA-256·크기·출처는 manifest에 기록한다. 캡처 날짜 미확인 표시는 유지한다.
- 공개 접속 링크는 기존 Azure 웹·모바일 주소를 사용한다. 로컬·사설 주소는 개발 문서와 과거 재현 기록에만 남긴다.
- 발표자료는 제공된 PPTX를 변환한 63페이지 PDF다. 기존 PPTX는 작성 당시의 자료이며 최신 화면 목록이 아니다.

## 개발 이력과 최신 안내

과거 목업은 `docs/design/archive/mockups/`에 보존하고 ‘과거 시안’ 표시 및 최신 화면 링크를 추가했다. 디자인 색상·배치 기준은 현재 Azure 화면 소개와 구분한다. 당시 설계·시험·실패 기록을 최신 성공 기록으로 덮어쓰지 않는다.

요구사항·아키텍처·보안·시연 문서의 진입 안내는 [현재 구성](../architecture/current-demo-20261017.md)과 [문서 안내](../README.md)로 연결한다. 과거 로그의 PASS, 700장 수신 완료나 테스트 수를 새 배포의 실적으로 재사용하지 않는다.

## 확인 범위

Azure 공개 진입점과 대표 정적 파일은 읽기 전용으로 조회했다. 대표 스타일 6개는 로컬과 일치한다. 진입 HTML과 앱 스크립트는 차이가 있으므로 저장소 전체를 Azure 배포본과 동일하다고 주장하지 않는다. 소스에는 배포본에 없는 방어 코드도 있어 무조건 역복사하지 않는다.

이 작업은 문서·정적 소개 범위다. 로그인 후 전체 화면을 새로 캡처하거나, Azure·병원·인증·접근정책을 수정하는 작업은 수행하지 않았다. 현재 실행 상태와 미검증 범위는 [구성 안내](../architecture/current-demo-20261017.md)를 따른다.
