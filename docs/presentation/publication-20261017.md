# 공개 포트폴리오 갱신 기준

2026-10-17: README와 /docs GitHub Pages 소개 페이지를 현재 시연 흐름에 맞춰 개편했다.
출처는 사용자가 제공한 「Medi Q 증적.zip」이다. 원본 ZIP은 변경하지 않았다.

- 공개 자산은 `docs/assets/portfolio-20261017/`의 7개 화면으로 제한한다.
- 이미지 자체를 생성·변형하지 않았다. 원본 바이트 해시를 manifest에 남겼다.
- 로그인 계정 선택 3개, QR 티켓, 내부 Azure 자원 화면, 중복 이미지, PDF와 APK는 새 공개 자산에서 제외했다.
- 캡처에서 확인한 합성 환자·가상 병원 UI를 사용한다. 브라우저 계정·인증코드·토큰 원문은 새 자료에 포함하지 않는다.
- 과거 자료는 Git 이력과 해당 문서의 기준일을 보존한다. 이전 목업과 내부 테스트 경로를 최신 서비스 링크로 안내하지 않는다.
- 고정 전체 테스트 수, 100% 차단, 700장 전량 무결성 완료, 근거 없는 응답시간·법률 해석은 소개에서 제거했다.
- 공유·접수·CT·관제 화면은 캡처 기반 설명이다. 소개 페이지에서 실제 API 요청이나 QR 발급을 하지 않는다.
- 개발용 URL은 개발 문서로 옮겼다. 공개 CTA는 기존 Azure 웹·모바일 주소를 사용한다.

현재 서비스 기준과 검증 한계는 [현재 구성](../architecture/current-demo-20261017.md)을 따른다.
과거 `docs/presentation/screenshots/`는 이번 새 소개 갤러리의 출처로 연결하지 않는다.
기존에 이미 공개된 파일의 Git 이력 삭제·정리는 이번 배포에서 수행하지 않는다.
