# 원본 시연 캡처 보관

이 폴더는 제공받은 원본 증적 보관용입니다. 파일 순서·이름이나 과거 설명을 현재 Azure 서비스의 화면 목록으로 사용하지 않습니다.

공개 소개에는 선별한 8개 캡처만 사용합니다. [현재 시연 화면 모음](https://sureasdufo1-hue.github.io/Highpass-Project/presentation/gallery.html)에서 확인하세요. [출처·SHA-256](../../assets/portfolio-20261017/manifest.json)에 원본과의 일치를 기록합니다.

당시 캡처의 사용자·검사·상태·수치는 합성 시연 환경 기준입니다. 캡처만으로 로그인·전송·임상·보안 인증 완료를 판단하지 않습니다.
