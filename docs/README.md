## 자료를 구분하는 방법

| 구분 | 위치 | 읽을 때 주의할 점 |
|---|---|---|
| 공개 화면 자료 | `assets/portfolio-20261017/`, `presentation/gallery.html` | 선별한 합성 시연 캡처. 실시간 화면이 아님 |
| 현재 구성 안내 | `architecture/current-demo-20261017.md` | 증적 날짜와 미검증 항목 확인 |
| 요구사항·보안 기준 | `REQUIREMENTS.md`, `ARCHITECTURE.md`, `SECURITY.md` | 목표 설계와 실행 증적을 구분 |
| 개발·검증 기록 | `implementation/`, `operations/`, `evidence/`, `design/` | 해당 기록의 날짜와 실행 환경에 한정 |
| 과거 화면 목업 | `design/archive/mockups/` | 현재 서비스가 아닌 개발 이력 |

로컬 주소·사설 IP는 개발·시험 재현용이며 공개 시연 링크가 아닙니다. 과거 기록의 PASS나 화면을 최신 배포 검증으로 재사용하지 않습니다. 이전 PPTX는 작성 당시의 발표자료이며, 최신 공개 발표자료 링크는 위 PDF입니다.

이 정리는 공개 자료와 안내를 맞추는 작업입니다. 배포 파일을 소스에 역복사하거나, 인증·동의·영상 접근 로직을 바꾸지 않습니다.
