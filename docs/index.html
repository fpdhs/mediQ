환자 CT 연결 장애 복구

Azure NIC와 운영체제의 보조 IP 상태가 달라 영상 연결이 끊겼습니다. 주소를 복구하고 영구 설정을 추가했습니다. 이후 환자가 CT 표시를 직접 확인했습니다.

타 리전 DR 대기 환경

주 서버의 PostgreSQL을 타 리전 대기 DB로 비동기 복제합니다.

Japan East주 서버 DB비동기 복제 →East Asia읽기 전용 대기 DB

확인 당시 두 DB의 복제 위치(LSN)가 일치했고, 대기 DB에서는 쓰기 요청이 거부됐습니다. Traffic Manager는 별도 비활성 검증 환경이며, 실제 장애 시 서버 전환과 DB 승격, 복구 시간(RTO)·데이터 손실 범위(RPO)는 아직 검증하지 않았습니다. Key Vault의 타 리전 복구도 추가 검증이 필요합니다.
