# MediQ UI Reference Screenshots

프로젝트 화면을 기능별로 찾기 쉽게 정리한 참고 스크린샷입니다. 파일명은 `역할/기능/상태`를 나타내며, 이 폴더는 문서·디자인 참고용이고 웹 런타임 자산(`public/`)이 아닙니다.

- 원본 첨부 파일은 임시 폴더에서 변경하거나 삭제하지 않았습니다. 아래 파일은 프로젝트 내 관리용 복사본입니다.
- 첨부 순서 #6/#7, #9/#10, #16/#17, #18/#19는 SHA-256이 동일한 중복 캡처입니다. 파일은 모두 보존했습니다.
- #2/#18/#19에는 계정 선택 화면의 이메일/계정 식별자가 보여 `authentication/private/`에 두고 Git에서 제외했습니다. 외부 공유나 커밋 전에는 비식별화가 필요합니다.
- 화면에 보이는 의료 사례는 합성 시연 UI로 분류했으며, 실제 운영 또는 임상 적합성의 증거가 아닙니다.
- 참고 이미지 정리만 수행했습니다. `public/` 화면 자산을 교체하지 않았고 Azure 배포도 하지 않았습니다.
